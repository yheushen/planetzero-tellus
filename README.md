# Planet Zero: tell us

This repository holds no code. It is where readers of [planetzero.ai](https://planetzero.ai) tell us when they think an answer, a number or a check on the site is wrong.
Every report here is public, and so is our reply: the checker can be checked too.
To report something, open a new issue with the link to the answer or page and what you think is wrong.
No GitHub account? Use the "or email us" link beside "Tell us" on the site.
